---
title: Data export and key revocation
description: Download a copy of an account's data and revoke the API key you are calling with; account deletion happens only in the app.
accent: developer
---

Use these endpoints to build a data-download button, or a sign-out step that revokes the key a tool was using. Both act on the key owner's own account and do not accept `?account=`.

<Callout type="warning">
Exports and key revocation are high-impact. An export contains personal data about the account, so store the file as carefully as a password. A revoked key cannot be restored. Confirm with a person before calling these routes from an automation.
</Callout>

API access needs a Honey Bee plan or above; see the [developer overview](/developers). Errors and rate limits follow [Requests, errors and limits](/developers/api-conventions#errors). Timestamps in these responses are Unix milliseconds.

Accounts can be deleted only in the Hive3 app, in <UI>Settings</UI> ([Delete your account](/account/privacy-and-data#delete-your-account)). Since API and CLI 0.5.0 no API route, key or scope can request, cancel or undo an account deletion; `POST` and `DELETE /api/v1/account/deletion` and the `account:destroy` scope are gone. While an account is waiting to be deleted, its keys return `401 invalid_api_key`.

Each endpoint shows curl. Endpoints with a request body also show JavaScript and Python; the others follow the same pattern with the same headers.

## Export account data

<Endpoint method="POST" path="/api/v1/account/export" scopes={["account:read", "account:write", "communities:read", "resources:read", "tickets:read", "payments:read", "feedback:read", "ai:read", "credentials:read"]}>

Builds a ZIP archive of CSV files with the account's profile, sign-in methods, linked wallets, memberships, follows, notifications, billing records, feedback and owned resources, and returns a download link. Private direct and community messages are not included. Exports are kept for 7 days. A repeat request while an unexpired export exists returns that file instead of building another.

Because the archive covers every area, the key needs all the scopes above: `account:write` plus the read scope of each area in the file. A Full access key created after the 0.5.0 update has them all; an older key, or a Read only key, does not.

Limited to 2 requests per hour, and to 2 newly built exports per day. There is no request body.

<Tabs labels={["curl","JavaScript","Python"]}>
<Tab>

```bash
curl -X POST https://app.hive3.tech/api/v1/account/export \
  -H "Authorization: Bearer $HIVE_API_KEY"
```

</Tab>
<Tab>

```js
const res = await fetch("https://app.hive3.tech/api/v1/account/export", {
  method: "POST",
  headers: { Authorization: `Bearer ${process.env.HIVE_API_KEY}` },
});
const { data } = await res.json();
```

</Tab>
<Tab>

```python
import os, requests

res = requests.post(
    "https://app.hive3.tech/api/v1/account/export",
    headers={"Authorization": "Bearer " + os.environ["HIVE_API_KEY"]},
)
data = res.json()["data"]
```

</Tab>
</Tabs>

Returns `201`. Download the file with a plain `GET` on `downloadUrl` and no `Authorization` header. Treat the link as a secret.

```json
{
  "data": {
    "exportId": "export_123",
    "fileName": "hive3-account-export-account_123-2026-10-27.zip",
    "downloadUrl": "https://example.com/download/export_123",
    "message": "Your account export is ready."
  }
}
```

- `400 invalid_request`: `An account export is already being prepared`, or `Account export limit reached. Try again tomorrow.`
- `403 insufficient_scope`: the key lacks one of the scopes above; `requiredScopes` lists them.
- `429 rate_limited`: more than 2 requests in an hour; wait for `Retry-After`.

</Endpoint>

## Revoke the current key

<Endpoint method="DELETE" path="/api/v1/account/keys/current" scopes={[]}>

Revokes the key that signs the request. Any valid key can revoke itself, including a read-only key, so a leaked key can always be disabled from the outside. The `hive3` command-line tool calls this route when you sign out. Revoked keys return `401 invalid_api_key`. Limited to 10 requests per minute.

```bash
curl -X DELETE https://app.hive3.tech/api/v1/account/keys/current \
  -H "Authorization: Bearer $HIVE_API_KEY"
```

Returns `200`.

```json
{ "data": { "revoked": true } }
```

- `401 invalid_api_key`: the key is already revoked, expired or unknown.
- `403 plan_required`: the account is below Honey Bee. Revoke the key from <Path items={["Settings", "Help & feedback", "Developer API keys", "Manage API keys"]} /> instead.

</Endpoint>
