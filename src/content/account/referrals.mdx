## Share your code

The <UI>Referral Program</UI> card shows <UI>Your code</UI>. Hive3 prepares it the first time you open the card.

- Select <UI>Copy code</UI> to copy the code. New people can enter it when they set up their profile.
- Select <UI>Copy share link</UI> to copy a sign-up link that already contains your code.

If a code has been deactivated, the card says so and the copy buttons are disabled.

## What the counts mean

| Count | Meaning |
|---|---|
| <UI>Referred signups</UI> | New accounts created through your share link. |
| <UI>Paid referrals</UI> | Only counts referrals after they purchase a subscription. |

The counts show how your code is being used. They are not a balance, and nothing on this card can be withdrawn.
